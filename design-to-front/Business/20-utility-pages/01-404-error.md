# Page Prompt: 404 Error Page

> **Design Node ID**: `uwKpi` | **Name**: "52 - 404 Error Page"
> **Route**: `*` (catch-all) | **View File**: `src/views/utility/NotFound.vue`

## Overview
Full-page 404 error screen shown when a route doesn't exist. Centered layout with large icon, title, description, and action buttons. Does NOT use AppShell (no sidebar/header).

## Layout
- Full viewport, centered vertically and horizontally
- Max content width: 520px
- Padding: 48px

## Content
- **Icon**: 96×96px circle, `#F5F5F5` bg, `file-question` or `search-x` icon 48px, `#616167`
- **Title**: "404" — Inter 64px 700, `#2A2933`, letter-spacing -2px
- **Subtitle**: "This page doesn't exist" — Inter 22px 700, `#2A2933`
- **Description**: "The link may be broken or the page may have been moved. If you typed the address, please check it for typos." — Inter 14px normal, `#616167`, centered, max-width 440px
- **Primary button**: "Go to dashboard" — pill, `#5749F4`, → `/business/dashboard`
- **Secondary button**: "Go back" — outline, → `router.back()`

## Help Link
